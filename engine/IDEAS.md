# Idea Inbox

Daily **idea sweeps** land here when the backlog runs dry. Each sweep appends one
`## YYYY-MM-DD` section with two groups: **Ideas** (dreamed up) and **Opportunities**
(grounded in a read of the actual repo). Bullets are plain `-`, never `- [ ]`, so the
backlog parser never mistakes an idea for a buildable task.

**Triage (Wolf, by hand):**
- **Queue it** → copy the bullet into `engine/BACKLOG.md` as a `- [ ]` task, then delete
  it from here.
- **Reject it** → move the bullet to `engine/IDEAS-rejected.md`; the next sweep reads that
  file and won't re-propose it.
- **Ignore it** → leave it here; it stays as standing context and won't be resurfaced.

## 2026-07-27

### Ideas (dreamed up)

- **Build it twice** — run one backlog line through two independent cycles on parallel branches and publish the diff between the two implementations. Nobody has an honest picture of how much an agentic build varies run-to-run on the *same* instruction; the loop is the only place that can measure it cheaply, and the answer ("the machine wrote a different thing both times, here they are") is the kind of finding a lab exists to produce. Costs one extra `claude -p` per experiment run and a throwaway branch.
- **A failure feed** — the loop currently erases its own failures. A cycle that throws hits `recoverToMain()` and the evidence is gone; the only trace is `engine/cycle.log`, which is gitignored and never leaves the box. Record each failed run (task, phase it died in, error) as a durable artifact and publish it. A public lab that only ships its successes is publishing an advertisement; the failures are the differentiated content.
- **Ask the lab** — client-only retrieval over the *bodies* of the Lab corpus, not just title+summary. 44 entries and growing weekly, and the only way in is `filterLabItems`' substring match over two fields. A build-time JSON index plus BM25 in the browser stays inside the no-server constraint and makes the archive usable as a reference instead of a scroll.
- **The engine as a forkable artifact** — `run-cycle.mjs` + `publish.mjs` + the registry + `guard.yml` are the site's most unusual asset and are currently readable only by cloning the repo. Extract them as a documented starter ("run your own always-on lab: backlog in, PRs out, path-guarded auto-merge") with the whatupwolf-specific bits parameterised. The interesting part is that the extraction itself is a cycle the machine can run on itself.
- **Listen to the lab** — a zero-key page that reads a Lab entry aloud with `speechSynthesis` (the machinery is already proven in `public/tools/voice-loop.html`), with the entry's `plain` reading as the spoken text since the technical one is unreadable out loud. Cheap, and it makes the three-level content model pay off in a second modality.

- `/video` is a nav link to a placeholder. `src/content/video/sample-demo.md` is the collection's only entry: title ends "(demo)", `summary` literally begins "Placeholder entry —", and `embed` is `https://www.youtube.com/watch?v=placeholder` — a dead URL. `src/components/Nav.astro:6` puts Video in the chrome of every page, and `src/pages/video.astro:24` makes the title an outbound link to that URL, so the whole route is one broken link presented as published work (the level variants at `:7-9` were even backfilled for it). Next tick `branchHasPr` (`engine/run-cycle.mjs:108`) says "no PR", the item is re-picked, `checkout -B` (`:281`) resets the branch to main, and the push is rejected non-fast-forward — the cycle fails, recovers, and repeats forever on the same item. `engine/run-experiment.mjs:220` already solved exactly this with `uniqueBranchName(base, parseRemoteBranches(ls-remote …))`; `run-cycle.mjs` imports neither helper.
- Post-failure recovery runs *outside* the single-instance lock. In both runners the lock is released in `main()`'s `finally` (`engine/run-cycle.mjs:245-249`) and `recoverToMain()` is called from the outer `catch` at the bottom of the file (`:385-391`, same shape at `engine/run-experiment.mjs`'s tail). That is precisely the corruption the lock was built for. Move the recovery inside the locked scope.
- `shortTitle` collapses an annotated backlog line to its status prefix. It takes the lead clause before the first `: ` or spaced dash (`engine/lib.mjs:41`), so `branchForItem` on the two annotated lines in `engine/BACKLOG.md` (`:58`, `:69`) returns `lab/built` and `lab/superseded-by-tier-9-pr-30` (verifiable: `node -e "import('./engine/lib.mjs').then(L=>console.log(L.branchForItem('(BUILT — PR #22 open) Close the …')))"`). Inert while those items are `[x]` — but `BACKLOG.md:55-57` *instructs* Wolf to annotate items with that exact prefix, and the skip guard keys off the line's current text, so annotating an item silently changes its branch identity: the "already built into a PR" check stops matching, and a rebuild would commit under the title "built". Strip a leading parenthetical before taking the lead clause.
- The guard workflow interpolates changed filenames into a shell string. `.github/workflows/guard.yml:73` ends the allowlist loop with `<<< '${{ steps.files.outputs.list }}'` — a GitHub expression pasted inside single quotes in a `run:` block, so a path containing a single quote closes the string and the remainder is shell, in the job that decides whether a PR auto-merges. Low exposure today (the file names come from our own machine, and a fork PR's token is read-only), but the fix is mechanical: pass the list through `env:` and read `"$LIST"` instead of splicing it into the script.
